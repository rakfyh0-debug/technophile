Logique algorithmique — Leçon 1

Qu'est-ce qu'un algorithme ?

Avant d'écrire la moindre ligne de code, il faut comprendre comment un problème se transforme en une suite d'étapes précises.

1La définition

Un algorithme est une suite finie et précise d'instructions qui permet de résoudre un problème ou d'accomplir une tâche, étape par étape. Ce n'est pas du code : c'est le raisonnement avant le code.

Une recette de cuisine est un algorithme : elle prend des ingrédients (l'entrée), applique une suite d'étapes (le traitement), et produit un plat (la sortie).

Un GPS
Entrée : ta position et ta destination. Traitement : calculer le meilleur chemin. Sortie : l'itinéraire à suivre, étape par étape.
Une notice de montage
Entrée : les pièces du meuble. Traitement : les étapes de montage dans l'ordre. Sortie : le meuble assemblé.
Une machine à laver
Entrée : le linge sale + un programme choisi. Traitement : trempage, lavage, essorage. Sortie : le linge propre.
Variable
Une boîte nommée qui contient une valeur pouvant changer (ex : age = 20).
Condition
Un choix : "si telle chose est vraie, alors fais ceci, sinon fais autre chose".
Boucle
Répéter une même action plusieurs fois, sans la réécrire à chaque fois.

4Pièges fréquents

Oublier un cas
Que se passe-t-il si a = b ? Un bon algorithme couvre tous les cas, pas juste le cas général.
Confondre = et ==
Dans un algorigramme, "=" veut souvent dire "affecter" une valeur, pas "tester l'égalité".
Sauter des étapes
Un algorithme se lit et s'exécute une étape à la fois, jamais "à l'instinct".
