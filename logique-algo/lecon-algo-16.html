Parcourir un tableau

Savoir créer un tableau ne suffit pas : il faut aussi savoir le parcourir — additionner ses éléments, chercher le plus grand, compter les occurrences. C'est là que les boucles rencontrent les tableaux.

1Pourquoi parcourir un tableau ?

Imagine un tableau de 100 notes. Pour calculer la moyenne, on ne va pas écrire notes[0] + notes[1] + … + notes[99]. On utilise une boucle qui parcourt le tableau élément par élément, du premier au dernier.

Le parcours est l'opération la plus courante sur un tableau. C'est un mariage naturel entre les boucles (Module 2) et les tableaux (Module 3).

Parcours
Visiter chaque élément du tableau une fois, dans l'ordre. On utilise une boucle Pour i de 0 à longueur-1.
Accumulateur
Une variable initialisée avant la boucle, qu'on met à jour à chaque tour. Ex : somme ← somme + tab[i].
Indice de parcours
La variable i de la boucle, qui prend successivement les valeurs 0, 1, 2, …, longueur-1.

2Le parcours classique avec Pour

La structure canonique — à connaître par cœur — utilise une boucle Pour avec un index qui va de 0 à longueur - 1 :

notes ← [12, 15, 8, 17, 10] Pour i de 0 à longueur(notes) - 1 faire Écrire notes[i] Fin Pour // Affiche : 12, 15, 8, 17, 10

En JavaScript, la même boucle s'écrit for (let i = 0; i < tab.length; i++). Les deux formes sont équivalentes.

3Les accumulateurs — additionner, multiplier

Pour additionner tous les éléments, on utilise une variable somme initialisée à 0 avant la boucle, qu'on incrémente à chaque tour.

notes ← [12, 15, 8, 17, 10] somme ← 0 Pour i de 0 à longueur(notes) - 1 faire somme ← somme + notes[i] Fin Pour moyenne ← somme / longueur(notes) Écrire "Moyenne : ", moyenne // 12.4

On peut faire la même chose pour un produit (initialisé à 1) ou pour un compteur (initialisé à 0) :

// Produit de tous les éléments produit ← 1 Pour i de 0 à longueur(tab) - 1 faire produit ← produit * tab[i] Fin Pour // Compter les éléments pairs compteur ← 0 Pour i de 0 à longueur(tab) - 1 faire Si tab[i] % 2 == 0 alors compteur ← compteur + 1 Fin Si Fin Pour

4Trouver le maximum ou le minimum

Pour trouver le plus grand élément d'un tableau, on initialise une variable max avec le premier élément, puis on compare chaque autre élément.

notes ← [12, 15, 8, 17, 10] max ← notes[0] // on suppose que le premier est le plus grand Pour i de 1 à longueur(notes) - 1 faire Si notes[i] > max alors max ← notes[i] Fin Si Fin Pour Écrire "Maximum : ", max // 17

On commence à i = 1 car on a déjà lu le premier élément pour initialiser max. Pour le minimum, même principe avec < à la place de >.

5Pièges fréquents

Boucle jusqu'à longueur
Pour i de 0 à longueur(tab) va déborder — le dernier index valide est longueur - 1. Erreur classique.
Oublier d'initialiser l'accumulateur
Si somme n'est pas initialisée à 0 avant la boucle, on ajoute à undefined, ce qui donne NaN.
Initialiser max à 0
Si tous les éléments sont négatifs, max = 0 serait retourné à tort. Toujours initialiser max au premier élément.
Tableau vide
Un tableau vide a une longueur de 0. La boucle ne fait aucun tour. max ← tab[0] renverrait undefined — à protéger avec Si longueur(tab) > 0 alors….
Modifier le tableau en le parcourant
Si on ajoute ou retire des éléments pendant un parcours, la longueur change et on saute des éléments. Dangereux.
Confondre index et valeur
Dans tab[i], i est l'index (0, 1, 2…) et tab[i] est la valeur. Ne pas faire tab[tab[i]] sans réfléchir.

6À toi de jouer

Trois fonctions classiques de parcours de tableau : somme, maximum, comptage.

Exercice — 3 mini-défis
Enchaîne ces 3 fonctions dans le terminal, dans l'ordre :
  • • sommeTableau(tab) — renvoie la somme de tous les éléments
  • • maximum(tab) — renvoie le plus grand élément (sans utiliser Math.max)
  • • compterOccurrences(tab, valeur) — renvoie combien de fois valeur apparaît dans le tableau
  • • Indices : for (let i = 0; i < tab.length; i++) { ... }
  • • sommeTableau([1,2,3,4]) → 10, maximum([5,3,9,1]) → 9
  • • compterOccurrences([1,2,1,3,1], 1) → 3
  • • Tape valider après chaque fonction pour débloquer la suivante
  • • Tape aide à tout moment, ou clear pour nettoyer l'écran
