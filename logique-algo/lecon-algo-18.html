Structures de données — Leçon 18

Les dictionnaires (objets clé-valeur)

Un tableau range ses valeurs par position (index 0, 1, 2…). Un dictionnaire les range par nom. Au lieu de dire « la 3ᵉ valeur », on dit « la valeur associée à la clé age ». C'est bien plus expressif.

1Pourquoi un dictionnaire ?

Imaginez stocker les informations d'un utilisateur dans un tableau : ["Alice", "alice@mail.com", 25, "Paris"]. Pour retrouver l'âge, il faut se souvenir que c'est à l'index 2. Fragile, et illisible.

Avec un dictionnaire : { nom: "Alice", email: "alice@mail.com", age: 25, ville: "Paris" }. On accède directement à utilisateur.age. Le code parle de lui-même.

Dictionnaire (objet)
Une collection de paires clé → valeur. Chaque clé est unique dans le dictionnaire. En JS : { }.
Clé
Le nom qui identifie une valeur. Souvent une chaîne : "nom", "age". Doit être unique.
Valeur
Ce qui est stocké sous une clé. Peut être n'importe quel type : nombre, chaîne, tableau, autre dictionnaire…
Propriété
Autre nom pour « paire clé-valeur » quand on parle d'un objet. user.age lit la propriété age.

2Créer, lire, modifier

// Déclaration user ← { nom: "Alice", email: "alice@mail.com", age: 25 } // Lire une valeur (deux notations équivalentes) Écrire user.nom // "Alice" Écrire user["email"] // "alice@mail.com" // Modifier une valeur existante user.age ← 26 Écrire user.age // 26 // Ajouter une nouvelle propriété user.ville ← "Paris" Écrire user.ville // "Paris"

3Parcourir un dictionnaire

On ne parcourt pas un dictionnaire par index (0, 1, 2…) mais par clés. En JavaScript, deux méthodes principales :

user ← { nom: "Alice", age: 25, ville: "Paris" } // 1) Parcourir les clés Pour chaque cle dans cles(user) faire Écrire cle, " : ", user[cle] Fin Pour // nom : Alice // age : 25 // ville : Paris // En JavaScript : for (const cle in user) { console.log(cle, " : ", user[cle]); }

Pour tester si une clé existe, on utilise "age" in user (renvoie true ou false). Et Object.keys(user) renvoie un tableau de toutes les clés.

4Trois exemples concrets

Exemple 1 — Fiche de contact

contact ← { nom: "Alice Dupont", tel: "06 12 34 56 78", email: "alice@mail.com", entreprise: "ACME" } Écrire "Contacter ", contact.nom, " au ", contact.tel

Exemple 2 — Compteur de fréquences

Un dictionnaire qui compte combien de fois chaque mot apparaît.

mots ← ["pomme", "banane", "pomme", "cerise", "pomme"] compteur ← {} Pour i de 0 à longueur(mots) - 1 faire m ← mots[i] Si m dans compteur alors compteur[m] ← compteur[m] + 1 Sinon compteur[m] ← 1 Fin Si Fin Pour Écrire compteur // { pomme: 3, banane: 1, cerise: 1 }

Exemple 3 — Config d'application

config ← { theme: "dark", langue: "fr", notifications: Vrai } Écrire "Thème : ", config.theme

5Pièges fréquents

Clé inexistante
Lire user.telephone sur un objet sans cette clé renvoie undefined (pas d'erreur). Il faut tester avant.
Confondre . et [ ]
user.nom et user["nom"] sont équivalents. Mais si la clé contient un espace ou un tiret, il faut [ ] : user["nom complet"].
Confondre { } et [ ]
{ } = dictionnaire (clés nommées). [ ] = tableau (index numériques). Deux structures très différentes.
Clé dupliquée
Si on déclare deux fois la même clé dans un objet littéral, la seconde écrase la première. Pas d'erreur, mais une perte silencieuse.
Copie par référence
Comme les tableaux, user2 ← user1 ne copie pas : les deux pointent vers le même objet. Modifier l'un modifie l'autre.
Parcourir avec for…in
for (k in obj) parcourt toutes les propriétés, y compris celles héritées. Pour un objet propre, préférer Object.keys(obj).
