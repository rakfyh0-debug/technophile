Structures de données — Leçon 19

Les ensembles (sets) et dédoublonnage

Un tableau peut contenir 10 fois la même valeur. Parfois, ce n'est pas ce qu'on veut : on cherche les valeurs uniques. Un ensemble (set) garantit que chaque élément n'apparaît qu'une seule fois.

1Pourquoi un ensemble ?

Imaginez une liste de tags sur un article : ["web", "js", "web", "css", "js"]. Il y a des doublons. Pour afficher les tags uniques, il faut dédoublonner. Un set fait ça automatiquement.

Un set, c'est comme une liste où chaque valeur ne peut apparaître qu'une seule fois. Ajouter deux fois la même valeur n'a aucun effet — la deuxième est ignorée silencieusement.

Ensemble (set)
Une collection non ordonnée d'éléments uniques. Pas d'index, pas de doublons. En JS : new Set().
Dédoublonnage
Retirer tous les doublons d'une collection pour ne garder que les valeurs uniques.
Appartenance
Tester si un élément est dans un set. Avec set.has(x), c'est très rapide — bien plus qu'avec tab.includes(x).
Ensemble mathématique
Un set en programmation suit la même idée qu'en maths : on peut faire des unions, intersections, différences.

2Créer, ajouter, tester

// Créer un set vide s ← Ensemble() // Ajouter des valeurs (doublons ignorés) s.ajouter("rouge") s.ajouter("vert") s.ajouter("rouge") // ignoré, déjà présent Écrire s // {"rouge", "vert"} // Tester l'appartenance Écrire s.contient("rouge") // Vrai Écrire s.contient("bleu") // Faux // Taille du set Écrire taille(s) // 2

3Dédoublonner un tableau

L'usage le plus courant d'un set : retirer les doublons d'un tableau existant.

tags ← ["web", "js", "web", "css", "js"] // 1) Convertir en set → doublons supprimés uniques ← Ensemble(tags) // 2) Reconvertir en tableau resultat ← tableau(uniques) Écrire resultat // ["web", "js", "css"] // En JavaScript, en une ligne : const resultat = [...new Set(tags)];

Le ... (spread) « étale » les valeurs du set dans un nouveau tableau. C'est le raccourci à retenir : [...new Set(tab)] supprime les doublons en une opération.

4Union, intersection, différence

Un set supporte les opérations classiques de la théorie des ensembles. Trois exemples parlants :

Union — tous les éléments des deux

A ← {1, 2, 3} B ← {3, 4, 5} // Union : {1, 2, 3, 4, 5} union ← A ∪ B

Intersection — seulement ce qui est dans les deux

A ← {1, 2, 3} B ← {3, 4, 5} // Intersection : {3} inter ← A ∩ B

Différence — ce qui est dans A mais pas dans B

A ← {1, 2, 3} B ← {3, 4, 5} // Différence : {1, 2} diff ← A \ B

Cas concret — utilisateurs inscrits cette semaine vs la précédente :

Opération Résultat Signification métier
Union{1,2,3,4,5}Tous les utilisateurs vus sur 2 semaines
Intersection{3}Utilisateurs fidèles (présents les 2 semaines)
Différence{1,2}Utilisateurs partis (semaine 1 mais pas 2)

5Pièges fréquents

Un set n'a pas d'index
On ne peut pas faire s[0]. Un set n'est pas ordonné. Pour accéder par position, il faut le convertir en tableau.
Ne pas confondre taille et longueur
Un tableau a une longueur. Un set a une taille. Ce sont deux propriétés différentes.
Muter pendant un parcours
Ajouter ou retirer des éléments d'un set pendant qu'on le parcourt peut donner des résultats imprévisibles. Éviter.
Objets dans un set
Deux objets différents avec les mêmes valeurs ne sont pas considérés comme égaux. {a:1} et {a:1} sont deux entités distinctes pour un set.
NaN dans un set
Particularité JS : NaN est considéré comme égal à lui-même dans un set (uniquement le premier est gardé). Contre-intuitif.
Ordre non garanti
Un set ne promet pas l'ordre d'insertion de façon universelle. Si l'ordre compte, il faut trier après conversion en tableau.
