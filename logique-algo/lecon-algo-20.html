Structures de données — Leçon 20

Exercices récapitulatifs du Module 3

Cette leçon clôt le module. Pas de nouveau concept — juste cinq défis qui mélangent tout : tableaux, parcours, mutation, dictionnaires et sets. Des problèmes qui ressemblent à de vraies tâches de développement.

1Récapitulatif du Module 3

Six leçons, six briques. Voici la carte mentale à garder :

15 — Tableaux
Collections ordonnées. Index de 0 à longueur - 1. Premier piège : le décalage de 1.
16 — Parcours
Boucle Pour i de 0 à longueur-1. Accumulateurs, max/min, comptage.
17 — Mutation
push, pop, shift, splice. Attention : ces méthodes mutent le tableau.
18 — Dictionnaires
Paires clé→valeur. Accès direct par nom. Parcours avec for…in ou Object.keys.
19 — Ensembles (sets)
Éléments uniques, non ordonnés. Dédoublonnage, appartenance, union/intersection/différence.

2Méthode pour aborder un défi

Ces défis sont plus longs que ceux des leçons précédentes. Prends 2 minutes pour réfléchir avant de coder.

Règles d'or :

  • Teste à la main avec un tout petit tableau (2-3 éléments) avant de lancer le vrai test.
  • Attention aux cas limites : tableau vide, un seul élément, tous identiques, valeurs négatives.
  • Ne mute pas ce que tu ne dois pas. Si l'énoncé dit « renvoie une copie », fais [...tab] ou tab.slice() d'abord.

3Cinq défis progressifs

Défi 1 — Somme et moyenne
Calcule la somme et la moyenne des notes. Arrondis la moyenne à 2 décimales.
  • • statsNotes(notes) — renvoie { somme, moyenne, count }
  • • moyenne = null si le tableau est vide
Défi 2 — Filtrer et trier
À partir d'une liste de nombres, garde uniquement ceux positifs, triés du plus petit au plus grand.
  • • positifsTries(tab) — renvoie un tableau de positifs triés
  • • Ne modifie pas le tableau original
Défi 3 — Compteur de mots
À partir d'une phrase, compte combien de fois chaque mot apparaît (sans ponctuation).
  • • compterMots(phrase) — renvoie { mot: count, ... }
  • • Ignore la ponctuation et les espaces multiples
Défi 4 — Fusion de listes sans doublons
Fusionne deux listes en une seule sans doublons, dans l'ordre d'apparition.
  • • fusionner(a, b) — renvoie le tableau fusionné, ordre préservé
  • • fusionner([1,2], [2,3]) → [1,2,3]
Défi 5 — Inventaire (le plus complet)
À partir d'un tableau de produits {nom, prix, qte}, calcule le total et renvoie l'inventaire enrichi.
  • • inventaire(produits) — renvoie { total, nbProduits, plusCher }
  • • total = somme des prix × qte
  • • plusCher = nom du produit au prix le plus élevé

4À toi de jouer

Les 5 défis se font dans le terminal, dans l'ordre. Chaque fonction débloque la suivante. Prends le temps de tester tes cas limites à la main entre les défis.

Exercice — 5 défis enchaînés
Termine le Module 3 en validant ces 5 défis :
  • • statsNotes(notes) — objet avec somme, moyenne, count
  • • positifsTries(tab) — copie filtrée et triée
  • • compterMots(phrase) — dictionnaire mot→compte
  • • fusionner(a, b) — fusion sans doublons
  • • inventaire(produits) — total + plus cher
  • • Indices : Object.keys, sort, Set, reduce ou boucles classiques
  • • Tape valider après chaque fonction pour débloquer la suivante
  • • Tape aide à tout moment, ou clear pour nettoyer l'écran
Objectif
1/5 — Implémente statsNotes(notes) : { somme, moyenne, count }.
  • • valider → lance les tests
  • • aide → revoir la consigne
  • • clear → nettoyer l'écran
