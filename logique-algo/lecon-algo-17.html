Structures de données — Leçon 17

Ajouter, retirer, modifier

Un tableau n'est pas figé. On peut ajouter un élément à la fin, retirer celui du milieu, remplacer une valeur. Chaque opération a sa méthode attitrée — voici les cinq à connaître.

1Un tableau est vivant

Dans une vraie application, les données changent constamment : un nouvel élève s'inscrit, une note est corrigée, un article est supprimé du panier. Un tableau doit pouvoir s'adapter.

Chaque langage propose ses propres méthodes. En JavaScript, les cinq plus courantes sont push, pop, shift, unshift, splice. On les voit une par une.

Muter
Modifier le tableau sur place — le tableau d'origine change. push, pop, splice mutent.
Copier
Créer un nouveau tableau sans toucher à l'original. concat, [...tab], slice créent des copies.
Position (début / fin / milieu)
Chaque méthode cible une zone précise du tableau. Savoir laquelle utiliser évite les opérations manuelles compliquées.

2Ajouter des éléments

push — à la fin

fruits ← ["pomme", "banane"] fruits.push("cerise") Écrire fruits // ["pomme", "banane", "cerise"]

unshift — au début

fruits ← ["banane", "cerise"] fruits.unshift("pomme") Écrire fruits // ["pomme", "banane", "cerise"]

En pseudo-code générique, on peut aussi écrire ajouter(fruits, "cerise") ou fruits[longueur(fruits)] ← "cerise". Les méthodes du langage font la même chose en plus lisible.

3Retirer des éléments

pop — le dernier

fruits ← ["pomme", "banane", "cerise"] dernier ← fruits.pop() Écrire dernier // "cerise" Écrire fruits // ["pomme", "banane"]

shift — le premier

fruits ← ["pomme", "banane", "cerise"] premier ← fruits.shift() Écrire premier // "pomme" Écrire fruits // ["banane", "cerise"]

splice — n'importe où

fruits ← ["pomme", "banane", "cerise", "datte"] // Retirer 1 élément à l'index 1 fruits.splice(1, 1) Écrire fruits // ["pomme", "cerise", "datte"] // Retirer 2 éléments à partir de l'index 0 fruits.splice(0, 2) Écrire fruits // ["datte"]

splice(index, combien) retire combien éléments à partir de index. C'est la méthode la plus flexible — et la plus dangereuse, car elle mute le tableau.

4Modifier un élément existant

Pour remplacer une valeur, on écrit directement à l'index :

notes ← [12, 15, 8, 17, 10] notes[2] ← 14 Écrire notes // [12, 15, 14, 17, 10] // Modifier plusieurs éléments notes[0] ← 10 notes[4] ← 12 Écrire notes // [10, 15, 14, 17, 12]

5Pièges fréquents

Confondre push et concat
push modifie le tableau d'origine et renvoie la nouvelle longueur. concat renvoie un nouveau tableau. Ne pas mélanger.
pop/shift renvoient l'élément
pop() et shift() renvoient l'élément retiré. Si on ne le stocke pas, il est perdu. Ce n'est pas un simple « retirer ».
Modifier pendant un parcours
Ajouter ou retirer des éléments pendant une boucle for décale les index et fait sauter des éléments. À éviter absolument.
splice mal argumenté
splice(2) retire tout à partir de l'index 2. splice(2, 1) retire un seul élément. Ne pas oublier le deuxième argument.
Index hors limites
Écrire tab[100] ← 5 sur un tableau de 3 éléments crée des « trous ». La longueur passe à 101, mais les cases 3 à 99 sont vides. À éviter.
Croire que push copie
tab.push(autreTab) ajoute le tableau entier comme un seul élément, pas ses valeurs. Utiliser push(...autreTab) (spread) pour aplatir.

6À toi de jouer

Trois fonctions qui manipulent un tableau en l'ajoutant, le retirant et le modifiant. Attention : certaines doivent renvoyer une copie, pas muter l'original.

Exercice — 3 mini-défis
Enchaîne ces 3 fonctions dans le terminal, dans l'ordre :
  • • ajouterFin(tab, val) — renvoie une copie du tableau avec val ajouté à la fin
  • • retirerIndex(tab, i) — renvoie une copie du tableau sans l'élément à l'index i
  • • remplacerIndex(tab, i, val) — renvoie une copie avec l'élément i remplacé par val
  • • Indices : [...tab] pour copier, .push(), .splice()
  • • ajouterFin([1,2], 3) → [1,2,3], retirerIndex([1,2,3], 1) → [1,3]
  • • Le tableau original passé en argument doit rester inchangé
  • • Tape valider après chaque fonction pour débloquer la suivante
  • • Tape aide à tout moment, ou clear pour nettoyer l'écran
Objectif
1/3 — Implémente ajouterFin(tab, val) : copie avec val à la fin.
  • • valider → lance les tests
  • • aide → revoir la consigne
  • • clear → nettoyer l'écran
