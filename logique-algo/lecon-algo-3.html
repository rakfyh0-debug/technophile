Logique algorithmique — Leçon 3

Les données : variables, constantes et types

Un algorithme sans données ne sert à rien. Avant de calculer, comparer ou décider, il faut savoir où ranger les valeurs et de quelle nature elles sont.

1Deux boîtes différentes : variable et constante

Pour stocker une information, un algorithme utilise des boîtes nommées. Il y en a deux sortes, et la différence est essentielle.

Variable
Une boîte dont la valeur peut changer pendant l'exécution. On la déclare une fois, on peut la modifier autant de fois qu'on veut.
Constante
Une boîte dont la valeur est fixée une fois pour toutes. Après sa déclaration, on n'y touche plus jamais.

Pourquoi cette distinction ? Parce que les deux jouent des rôles différents dans un algorithme :

  • Une variable mémorise un état qui évolue : le score d'un joueur augmente, un compteur s'incrémente, une température change.
  • Une constante mémorise une règle du monde qui ne bouge pas : le nombre de jours dans une semaine (7), la vitesse de la lumière, un taux de TVA légal, la valeur de π.

Quand tu lis du code, une constante bien nommée te dit immédiatement : « cette valeur ne changera pas, tu peux t'y fier ». C'est une forme de documentation gratuite.

Convention d'écriture — pour les repérer d'un coup d'œil, on écrit les constantes en MAJUSCULES :

// Variables (minuscules) age ← 25 score ← 0 temperature ← 37.5 // Constantes (MAJUSCULES) JOURS_SEMAINE ← 7 TVA_STANDARD ← 0.20 PI ← 3.14159

Le symbole ← se lit « reçoit ». On dit qu'on affecte une valeur à une variable. Ne pas confondre avec = qui, lui, servira à tester une égalité (Leçon 6).

2Les 4 types de base

Toute valeur a un type : sa nature. Le type détermine ce qu'on peut faire avec la valeur (additionner, concaténer, comparer…). Quatre types suffisent pour 90 % des algorithmes débutants.

Entier (integer)
Un nombre sans virgule : 0, 7, -42, 1000. Sert à compter.
Réel (float)
Un nombre avec virgule : 3.14, -0.5, 1.68. Sert à mesurer.
Chaîne (string)
Du texte, entre guillemets : "Alice", "bonjour". Peut contenir lettres, chiffres et symboles.
Booléen (boolean)
Deux valeurs possibles : Vrai ou Faux. Sert à mémoriser une réponse à une question fermée.

Un exemple de déclaration qui couvre les 4 types :

nom ← "Alice" // chaîne age ← 25 // entier taille ← 1.68 // réel estÉtudiant ← Vrai // booléen

Chaque boîte a un nom (l'étiquette), une valeur (le contenu) et un type (la nature du contenu). Le type dépend de la valeur que tu ranges dedans, pas du nom que tu lui donnes.

3Pourquoi le type compte autant

Le type n'est pas une décoration : il détermine ce que tu peux faire avec la valeur, et ce que ça donne. Le même symbole + ne se comporte pas pareil selon les types en jeu.

5 + 3 // 8 → addition "5" + "3" // "53" → concaténation (on colle les textes) 5 + "3" // ambigu : selon le langage, ça peut donner "53" ou 8 5 == 5 // Vrai → même valeur, même type "5" == 5 // selon le langage : Vrai (converti) ou Faux (strict)

Ce genre de piège cause une grande partie des bugs des débutants. La règle à retenir :

Avant de manipuler une valeur, demande-toi systématiquement de quel type elle est. Un texte n'est pas un nombre, même s'il ressemble à un nombre.

Autre conséquence : le type d'une valeur détermine ce que tu peux lui demander :

  • Sur un nombre : additionner, soustraire, comparer avec <, calculer un modulo.
  • Sur une chaîne : mesurer sa longueur, la mettre en majuscules, chercher un caractère dedans.
  • Sur un booléen : combiner avec ET, OU, NON.

Essayer d'ajouter deux booléens n'a aucun sens. Essayer de mesurer la longueur d'un entier non plus. Le type dicte la grammaire.

4Pièges fréquents

Mettre une constante en variable
Techniquement ça marche, mais tu perds l'information « cette valeur ne bougera pas ». Une constante bien nommée rend l'intention lisible.
Confondre "5" et 5
Le premier est une chaîne d'un caractère, le second un entier. "5" + "3" donne "53", pas 8.
Nommer mal ses boîtes
a, b, x, truc, temp2... Six mois plus tard, tu ne comprendras plus ton propre code. ageUtilisateur vaut mieux que a.
Réutiliser un nom
Déclarer score pour un compteur de vies, puis réutiliser score pour un prix : deux rôles dans la même boîte, source de confusion.
Mélanger les types sans le vouloir
Lire l'âge d'un utilisateur depuis un formulaire te donne une chaîne ("25"), pas un entier. Il faudra le convertir avant de calculer.

5À toi de jouer

Trois fonctions qui inspectent le type d'une valeur. En JavaScript, typeof x renvoie "number", "string", "boolean" etc. Pour distinguer un entier d'un réel, on utilise Number.isInteger(x).
